# manacutter

Exploration of a FFXIV web API powered by [Lumina](https://github.com/NotAdam/Lumina), with goal of replacing the aging XIVAPI service.

> [!IMPORTANT]
> `manacutter` has been superseded by [`boilmaster`](https://github.com/ackwell/boilmaster), which is now serving in production as [v2.xivapi.com](https://v2.xivapi.com/). This repository is archived for historical purposes.
